# Отчёт: концепт-сайт «КАЛИБР»

Одностраничный сайт вымышленной мастерской ремонта и реставрации механических часов в Москве. Подача — технический чертёж: номера позиций, выноски, размеры в миллиметрах, штамп листа. Палитра: графит, латунь, слоновая кость, линии цвета старой бумаги. Шрифты: Cormorant Garamond + IBM Plex Sans + IBM Plex Mono (все с кириллицей).

## Как реализована разборка

- **Графика.** Часы — инлайн-SVG из 10 деталей: стекло, безель, стрелки, циферблат, механизм (платина с перляжем, мосты с «женевскими волнами», барабан, колёса передачи, анкерное колесо, вилка, рубиновые камни), баланс со спиралью, корпус с ушками, задняя крышка с гравировкой по окружности, заводная головка, ремешок. Генерирует их `tools/gen-watch.mjs`.
- **Псевдо-3D без WebGL.** Каждая деталь лежит в группе `.tilt`; наклон — `scale(k, 1)`, то есть ортографическая проекция поворота диска. Стрелки и колёса вращаются внутри наклонённых групп, поэтому проекция честная.
- **Прокрутка.** ScrollTrigger закрепляет сцену (pin) на 2,6 высоты экрана (на телефоне 2,2) и со `scrub` отдаёт прогресс 0…1. По прогрессу: hero-текст уходит → часы едут в центр → наклон → разлёт → осевая штрихпунктирная линия → выноски рисуются через `stroke-dashoffset` (линия, затем полка, затем текст) → размерная линия «Ø 39,0».
- **Раскладка от экрана.** `viewBox` пересчитывается под реальный размер сцены. Широкий экран — горизонтальный разлёт, подписи двумя рядами (сверху и снизу) с раскладкой без пересечений. Портрет/телефон — **упрощённый вертикальный разлёт**: подписи колонкой справа, ремешок скрыт.
- **Живые детали.** Секундная стрелка «тикает» 8 раз в секунду (как у механики на 28 800 пк/ч), часовая и минутная — по текущему времени; баланс качается, колёса вращаются. Вне экрана всё на паузе.
- **Лупа.** На компьютере над часами курсор превращается в лупу ×2,5 (живая копия часов через `<use>` в круглом `clipPath`).
- **Фолбэки.** `prefers-reduced-motion` → без закрепления и анимаций сразу показывается статичная схема «в разборе» с выносками. Без JS → собранные часы + полная текстовая спецификация. Если GSAP не загрузился → тот же статичный режим.

## Круги «скриншот → исправление»

1. **Круг 1:** заголовок разбора наезжал на верхний ряд выносок → заголовок в одну строку, ряд подписей опускается под него; цифры на циферблате спорили с надписью КАЛИБР → убраны; царапины и трещина в кейсах были не в масштабе (вылезали за корпус) → пересчитаны в координатах символа; дом на схеме стоял на дороге → схема перерисована; шаг 04 растягивался по высоте графика → сетка `auto auto 1fr`; «чипы» типа часов наследовали капслок → исправлено; полноэкранные скриншоты были пустыми из-за `scroll-behavior: smooth` → прокрутка `instant` в проверках.
2. **Круг 2:** горизонтальный скролл 401 px на телефоне (скрытая таблица графика) → обёртка `div.visually-hidden`; на телефоне часы налезали на кнопки и уходил текст → ушки часов не заходят на текст, градиент под hero-текстом, кнопки в одну строку; подписи 07 и 09 налезали в вертикальном разлёте → шаг 54 единицы; бургер обрезался у края; после отправки формы форма оставалась видимой (`display: grid` перебивал `hidden`) → `[hidden]{display:none!important}`; на 1920 hero не совпадал по левому краю с логотипом → общая переменная `--edge`; фон мобильного меню с линейкой выглядел грязно → однотонный.
3. **Круг 3 (производительность и детали):** LCP 4,5 с из-за скрытого до JS SVG → часы видны сразу и стоят там же, где их поставит раскладка; DOM −450 узлов; после этого раскладка на 1280 ошибочно выбирала «портрет» (мерилась до перехода в режим сцены) → исправлен порядок; подписи на 1280 мелкие → крупнее масштаб; добавлена размерная линия Ø 39,0; ячейки «срок» в прайсе переносились на планшете → `nowrap`; мелкий текст графика на телефоне → крупнее.

## Что упрощено и почему

- **3D — проекция в SVG, а не WebGL.** Легче, чётче, без фолбэков и проблем на слабых телефонах; для чертёжной подачи плоская проекция даже уместнее.
- **На телефоне ремешок в разлёте скрыт** (в ТЗ — «упрощённый вертикальный разлёт»), на широком экране он показан штрихпунктиром «условно».
- **Баланс качается медленнее реальных 4 Гц**, чтобы «тихо», а не дрожал.
- **Метро на схеме без названия** — чтобы не привязываться к реальной станции.
- **Lenis не подключён** — нативный скролл надёжнее с pin-секцией на мобильных.
- **Шрифты и GSAP лежат в репозитории**, а не на CDN — cdnjs недоступен из среды разработки, а локальные файлы ещё и быстрее.

## Идеи улучшения

1. Подсветка детали при наведении на строку спецификации (и наоборот — клик по детали в разборе прокручивает к её описанию).
2. Переключатель «вид спереди / вид сбоку» в разборе и сечение корпуса с размерами высоты.
3. Звук тиканья по кнопке (выключен по умолчанию) — сильный эмоциональный эффект для портфолио.
4. Калькулятор стоимости: тип механизма + симптомы → ориентировочная цена и срок.
5. Анимированная трасса тайм-грейфера (точки «до» расходятся, «после» — ровная линия) вместо столбиков.
6. Страница отдельного кейса с журналом работ по дням и фото-фиксацией.
7. Критический CSS в `<head>`, минификация CSS/JS — плюс 3–5 баллов к mobile Performance.
8. Английская версия и тёмная/светлая «бумажная» тема (синька ↔ калька).
9. Микроанимация логотипа: при наведении знак делает полный оборот минутной стрелки.

## Как открыть локально

```bash
python -m http.server 8080
```

Затем открыть `http://localhost:8080`. Или просто дважды щёлкнуть `index.html`.

## Как опубликовать на GitHub Pages

1. Слить ветку с работой в `main` (Pull request → Merge).
2. Репозиторий → **Settings** → **Pages**.
3. **Source:** «Deploy from a branch», **Branch:** `main`, папка `/ (root)` → **Save**.
4. Через 1–3 минуты появится ссылка `https://<логин>.github.io/kalibr-concept/`.
5. (Желательно) заменить `og:image` в `index.html` на полный адрес `https://<логин>.github.io/kalibr-concept/img/og.jpg`, чтобы обложка показывалась в мессенджерах.

Подробная инструкция для новичка — в `README.md`. Сайт сам не опубликован — GitHub Pages не включался.
