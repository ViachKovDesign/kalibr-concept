# КАЛИБР — концепт сайта часовой мастерской

Концепт-проект для портфолио веб-дизайнера. Вымышленная мастерская ремонта и реставрации механических часов в Москве. Подача — как технический чертёж: позиции, выноски, размеры в миллиметрах.

**Главная фишка:** при прокрутке фото часов на первом экране превращается в стопку фото-деталей, и они разлетаются на 8 позиций (exploded view), у каждой детали появляется чертёжная выноска с номером позиции. Стрелки идут по настоящему времени, баланс качается, колёса механизма вращаются. Над часами на компьютере работает курсор-лупа.

> Концепт-проект. Бренд вымышленный. Фотографии созданы с помощью ИИ. Дизайн и разработка — [ViachKovDesign](https://viachkovdesign.github.io)

## Что внутри

```
index.html          — вся страница (11 секций)
css/style.css       — стили
js/main.js          — разборка часов, лупа, шторки «до/после», форма, меню
vendor/             — GSAP 3.12.5 и ScrollTrigger (локальные копии)
fonts/              — шрифты Google Fonts (Cormorant Garamond, IBM Plex Sans, IBM Plex Mono), woff2
img/                — фавиконки, OG-обложка 1200×630
img/photo/          — фото для сайта: AVIF + WebP, 640/1280/2048
screenshots/        — скриншоты проверок
tools/              — служебные скрипты (генератор SVG, скриншоты, локальный сервер)
DECISIONS.md        — журнал решений
REPORT.md           — итоговый отчёт
```

Сайт — обычные HTML, CSS и JS, без сборщиков и `npm install`. Все пути относительные.

## Как открыть на своём компьютере

**Самый простой способ:** дважды щёлкнуть по `index.html` — страница откроется в браузере. Работает всё, кроме мелочей, которые браузеры ограничивают для файлов с диска.

**Правильный способ — через локальный сервер** (так сайт ведёт себя точно как в интернете):

1. Установите Python 3, если его нет (python.org → Downloads).
2. Откройте терминал в папке проекта (в Windows: зажмите Shift, правый клик по папке → «Открыть в терминале»).
3. Выполните:

   ```bash
   python -m http.server 8080
   ```

4. Откройте в браузере `http://localhost:8080`.
5. Остановить сервер — `Ctrl + C` в терминале.

Если установлен Node.js, можно запустить сервер, похожий на GitHub Pages (со сжатием gzip):

```bash
node tools/serve.mjs 8080
```

## Как опубликовать на GitHub Pages (пошагово)

1. Откройте репозиторий на GitHub.
2. Убедитесь, что нужные файлы лежат в ветке `main` (если работа в другой ветке — сначала создайте Pull Request и слейте его в `main`: вкладка **Pull requests → New pull request → Create → Merge**).
3. Перейдите в **Settings** (шестерёнка вверху страницы репозитория).
4. В меню слева выберите **Pages**.
5. В блоке **Build and deployment** → **Source** выберите **Deploy from a branch**.
6. В **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
7. Подождите 1–3 минуты и обновите страницу настроек — сверху появится ссылка вида `https://<ваш-логин>.github.io/kalibr-concept/`.
8. Откройте ссылку и проверьте, что всё работает. Сайт рассчитан на работу из подпапки — все пути относительные.

**OG-картинка при шаринге.** Чтобы ссылка в мессенджерах показывала обложку, некоторым сервисам нужен полный адрес картинки. После публикации замените в `index.html` строку
`<meta property="og:image" content="img/og.jpg">` на
`<meta property="og:image" content="https://<ваш-логин>.github.io/kalibr-concept/img/og.jpg">`.

## Как поменять часы

SVG-детали часов генерируются скриптом и вписываются прямо в `index.html` (между комментариями `<!-- GEN:… -->`). Если захотите поменять геометрию, цвета или график хода — правьте `tools/gen-watch.mjs` и запустите:

```bash
node tools/gen-watch.mjs
```

Тексты, цены, FAQ правятся прямо в `index.html`.

## Как обновить фото

Исходные PNG (16 ИИ-фото, ~47 МБ) в репозитории не хранятся — они лежат локально у автора. Папка `img/raw/` занесена в `.gitignore`. Сайту исходники не нужны: он использует только готовые файлы из `img/photo/`.

Чтобы пересобрать фото:

1. Положите PNG в `img/raw/` с прежними именами: `01-assembled-watch.png`, `02-sapphire-crystal.png` … `16-case-after-polishing.png` (полный список — в начале `tools/process-photos.mjs`).
2. Один раз установите `sharp`:

   ```bash
   npm i sharp
   ```

3. Запустите:

   ```bash
   node tools/process-photos.mjs
   ```

Скрипт выровняет детали разборки по центру и масштабу и запишет в `img/photo/` AVIF и WebP в трёх размерах (640/1280/2048). Если деталь снята иначе — поправьте её центр и ширину в массиве `LAYERS` в начале скрипта.

## Проверки (для разработчика)

```bash
node tools/serve.mjs 8090                               # сервер с gzip
node tools/shoot.mjs http://localhost:8090/ screenshots # скриншоты + проверка консоли, горизонтального скролла, формы
node tools/make-assets.mjs http://localhost:8090/       # пересоздать OG-обложку и PNG-фавиконки
npx lighthouse http://localhost:8090/ --view             # Lighthouse
```

Для `tools/shoot.mjs` и `tools/make-assets.mjs` нужен Playwright (`npm i -g playwright && npx playwright install chromium`).
